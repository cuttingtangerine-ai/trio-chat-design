# 公开范围与脱敏说明

本仓库采用从原设计中重新提炼通用规则的方式发布，没有复制原项目目录或提交历史。

## 已纳入

- 通用角色和房间权限矩阵。
- 自动交流预算、用户介入、任务投递和失败重试规则。
- 应用层可见性边界与共享上下文限制。
- 专门编写的虚构示例和后续验收清单。

## 未纳入

- 真实聊天、个人经历、关系设定、私人提示词和长期记忆。
- 数据库、日志、备份、浏览器状态与历史会话。
- 密码、令牌、Cookie、密钥或生产配置。
- 真实域名、服务器地址、机器账户、绝对路径和线程标识。
- 运行源码、可执行部署脚本及未重新验证的上线结论。

## 如何理解项目状态

这些内容来自个人项目的设计文档和开发记录，经过去身份化整理。仓库作为设计案例展示产品取舍，不承诺提供开箱即用软件，也不宣称当前线上版本已经通过全部验收。

后续若发布源码或截图，应单独审查新增文件及其提交历史。此说明只覆盖当前文档集合，不能替代后续发布前检查。
